# Study Lofi (React Hooks)

Website belajar bertema lofi, dibuat dengan React + Vite + Tailwind CSS.
Project ini dibuat untuk tugas eksplorasi React Hooks (`useState` dan `useEffect`).

## Komponen

| Komponen | Hook | Fungsi |
|----------|------|--------|
| `Counter` | `useState` | Menghitung jumlah sesi fokus yang selesai (+, -, Reset) |
| `TodoList` | `useState` | Daftar tugas belajar (tambah dan hapus) |
| `FetchData` | `useEffect` | Mengambil quote motivasi dari API dummy (dummyjson.com) |

Semua komponen ada di folder `src/components`.

## Cara menjalankan

```bash
npm install
npm run dev
```

Lalu buka `http://localhost:5173`.

## Teknologi

React, Vite, Tailwind CSS
